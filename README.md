# YTSearch CLI Website

React + Vite documentation and product site for **ytsearch-cli**, deployed to GitHub Pages at https://ytsearch-cli.rjryt.com.

## Development

```bash
npm install
npm run dev
npm run build
```

## Deployment

Push to `main`. GitHub Actions builds the Vite app and deploys `dist/` to GitHub Pages.

The custom domain is defined by `CNAME`.
